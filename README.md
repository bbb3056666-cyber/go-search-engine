# 简易搜索引擎

姓名 Top N、文档关键词搜索；页面可以直接添加姓名和文章。

实现方案、优势与缺点、工程化优化及文本搜索与文档搜索的差异见 [设计说明](设计说明.md)。

## 启动

在项目根目录运行：

```powershell
go run .
```

打开 http://127.0.0.1:8081。需要换端口时使用 `go run . -addr 127.0.0.1:8082`。

## 结构

```text
main.go              启动 Gin、查询/添加接口、文件追加
names.go             姓名哈希分块、map 计数、最小堆 Top K
search/engine.go     搜索引擎的数据结构
search/index.go      分批建索引、倒排段落盘、全局统计
search/storage.go    按位置读写文件、追加文章
search/tokenize.go   gse 分词
search/ranking.go    按词读取倒排段、BM25、Top K
search/search_test.go 搜索算法与文件定位测试
names_test.go        姓名统计测试
http_test.go         HTTP 接口与数据添加测试
web/index.html       页面、样式和交互
data/names.txt       10 万条模拟姓名，一行一个
data/documents.jsonl 约 1 万篇示例与模拟文章
data/tmp/           运行时生成的文档索引、姓名临时分桶
```

## 使用方法

- 页面输入关键词搜索文章，结果按 BM25 排序，可展开全文。
- 输入前 N 名（1–1000），点击统计，读取姓名文件，分 64 桶、逐桶计数，用同一个最小堆筛选结果。
- 展开“添加姓名”，追加一条记录；允许同名，再次统计时会增加次数。
- 展开“添加文章”，填写标题和正文。文章追加到原文文件，各词追加新的倒排段，并更新内存映射和全局统计，立即可搜。
- 页面添加的数据重启后仍保留；如果直接在磁盘编辑文档文件，则需要重启重建索引。
- 姓名统计的临时分桶保存在 data/tmp/ 下，统计结束后自动清理。

文章测试数据覆盖 Go 并发、数据库索引、Redis 缓存、HTTP 网络等 14 个主题，用于功能验证。

文档格式：

```json
{"id":"1","title":"Go 并发","content":"使用 goroutine 和 channel。"}
```

## 实现概述

姓名统计采用哈希分桶、逐桶 map 计数和全局最小堆，页面默认使用 64 桶。

文档启动时分批建立倒排索引，每批最多 1000 篇或约 1MiB 原始 JSON 数据。每个词的倒排表单独编码为 JSON，追加到 data/tmp/postings.jsonl。原文保留在 data/documents.jsonl。

内存保存词元到倒排段的位置映射、文章 ID 到原文的位置映射、文章长度和 BM25 全局统计。每个位置包含字节偏移量和字节长度，同一个词可对应多段位置。

查询通过 ReadAt 读取目标词的倒排段，累计全部候选的 BM25 分数，再用容量为 20 的堆筛选结果。标题权重为 2，正文权重为 1。最后按 ID 定位读取前 20 篇原文，返回总命中数和结果，按分数降序、同分 ID 升序排列。

分词使用 [gse](https://github.com/go-ego/gse) 内置简体中文词典的精准模式，标题、正文和查询共用分词规则，并进行小写转换及空白、标点过滤。

## 当前限制

- 候选分数 map 随命中文章数增长，位置映射和全局统计也占用内存。
- 每次启动覆盖重建 data/tmp/postings.jsonl。
- 分批构建和新增文章都会追加倒排段，暂不合并，尚未实现文章更新和删除。
- 姓名单桶限制为 100 万个不同姓名，超过时返回错误，尚未实现自动二次分桶。
- 当前使用模拟数据验证功能，尚未验证十四亿规模和整个进程低于 4GB 的峰值内存。
- 文档输入为 JSON 文本，暂不支持 PDF/Word 解析和用户权限管理。

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/search?q=关键词` | 搜索文章 |
| POST | `/api/names?k=100` | 统计姓名排名 |
| POST | `/api/names/add` | 添加姓名，JSON 字段：name |
| POST | `/api/documents` | 添加文章，JSON 字段：title、content |
